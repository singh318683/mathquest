# MathQuest Adventure 🧙

A story-based math game where kids solve real math problems to defeat monsters and complete adventures.

**Live game:** https://mathquest.vercel.app

## Chapters
| # | Chapter | Topic | Access |
|---|---------|-------|--------|
| 1 | The Goblin's Forest | Addition | Free |
| 2 | The Troll's Bridge | Subtraction | Free |
| 3 | The Dragon's Cave | Multiplication | Free |
| 4 | The Witch's Tower | Division | Premium |
| 5 | The Serpent's Sea | Fractions | Premium |
| 6 | The Dark Knight's Castle | Decimals | Premium |

## Tech Stack
- Vanilla HTML/CSS/JS — zero dependencies
- localStorage for XP and progress persistence
- Stripe Checkout for premium subscription ($1.99/month)
- Deployed on Vercel via GitHub
